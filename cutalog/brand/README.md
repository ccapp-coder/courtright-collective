# Cutalog — Brand Assets

**Concept: "The Clean Cut" — cut · a · log.** The wordmark is set in lowercase
Outfit Bold; every letter is intact except the `l`, which is sliced by one
shallow blade — its severed top turns ember and slides up along the cut. The
app mark repeats the same language: three catalog bars cut by a single blade,
their sliced-off ends in ember.

## Palette

| Name  | Hex       | Use                                  |
|-------|-----------|--------------------------------------|
| Ink   | `#1A1D22` | Primary mark, dark fields            |
| Paper | `#F7F5F0` | Light backgrounds, reversed mark     |
| Ember | `#F05A32` | Accent — appears only at the cut     |

## Files

- `cutalog-brand-sheet.png` — presentation sheet (wordmark, icon, reversed, palette)
- `cutalog-wordmark-ink.png` / `-paper.png` — wordmark on transparent (light / dark use)
- `cutalog-lockup-ink.png` / `-paper.png` — horizontal lockup, mark + wordmark
- `cutalog-icon-1024.png` — app icon, 1024×1024 rounded ink tile
- `cutalog-mark-transparent-ink.png` / `-paper.png` — bare sliced-bars mark, no tile
- `design-philosophy.md` — the guiding design philosophy
- `make_brand.py` — generator script (Pillow); all assets are reproducible from it.
  Font: Outfit Bold (Google Fonts, OFL) — same family as courtrightco.com.
  Blade angle: 18° on the wordmark, 16° on the icon.
